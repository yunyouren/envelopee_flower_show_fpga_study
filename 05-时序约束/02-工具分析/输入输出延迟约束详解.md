## 1. 输入延迟约束（Input Delay）

### 1.1 核心概念

**输入延迟（Input Delay）** 用于描述外部信号到达 FPGA 输入端口后，相对于参考时钟（物理时钟或虚拟时钟）的延迟范围，是约束外部设备到 FPGA 输入路径时序的核心手段。

### 1.2 作用机制

输入延迟约束告诉时序分析工具：
- **外部信号从其驱动时钟的有效沿到 FPGA 输入端口的延迟范围**
- **确保 FPGA 内部逻辑有足够时间完成信号采样**
- **避免建立/保持时间违规**

### 1.3 应用场景详解

#### 1.3.1 外部传感器数据接收

**场景描述**：外部温度传感器以 100MHz 时钟输出 8 位数据，传感器时钟未接入 FPGA。

```tcl
# 创建虚拟时钟模拟传感器时钟（100MHz）
create_clock -name VIRT_SENSOR_CLK -period 10

# 设置输入延迟约束
set_input_delay -clock VIRT_SENSOR_CLK -max 3.0 [get_ports SENSOR_DATA[*]]
set_input_delay -clock VIRT_SENSOR_CLK -min 1.0 [get_ports SENSOR_DATA[*]]

# 同时约束控制信号
set_input_delay -clock VIRT_SENSOR_CLK -max 2.5 [get_ports {SENSOR_VALID SENSOR_READY}]
set_input_delay -clock VIRT_SENSOR_CLK -min 0.8 [get_ports {SENSOR_VALID SENSOR_READY}]
```

#### 1.3.2 CPU 接口数据接收

**场景描述**：外部 CPU 以 150MHz 时钟向 FPGA 发送数据，CPU 时钟同时接入 FPGA。

```tcl
# 定义物理时钟（CPU_CLK，150MHz）
create_clock -name CPU_CLK -period 6.667 [get_ports CPU_CLK]

# 设置数据总线输入延迟
set_input_delay -clock CPU_CLK -max 2.0 [get_ports CPU_DATA[*]]
set_input_delay -clock CPU_CLK -min 0.5 [get_ports CPU_DATA[*]]

# 设置地址总线输入延迟
set_input_delay -clock CPU_CLK -max 1.8 [get_ports CPU_ADDR[*]]
set_input_delay -clock CPU_CLK -min 0.3 [get_ports CPU_ADDR[*]]

# 设置控制信号输入延迟
set_input_delay -clock CPU_CLK -max 1.5 [get_ports {CPU_WE CPU_OE CPU_CS}]
set_input_delay -clock CPU_CLK -min 0.2 [get_ports {CPU_WE CPU_OE CPU_CS}]
```

#### 1.3.3 高速 ADC 数据接收

**场景描述**：12 位 200MSPS ADC 输出数据，包含数据时钟（DCO）和帧时钟（FCO）。

```tcl
# 定义 ADC 数据时钟（200MHz）
create_clock -name ADC_DCO -period 5.0 [get_ports ADC_DCO]

# 设置 ADC 数据输入延迟（高速接口，延迟较小）
set_input_delay -clock ADC_DCO -max 1.5 [get_ports ADC_DATA[*]]
set_input_delay -clock ADC_DCO -min 0.2 [get_ports ADC_DATA[*]]

# 设置帧时钟输入延迟
set_input_delay -clock ADC_DCO -max 1.0 [get_ports ADC_FCO]
set_input_delay -clock ADC_DCO -min 0.1 [get_ports ADC_FCO]

# 设置溢出标志输入延迟
set_input_delay -clock ADC_DCO -max 2.0 [get_ports ADC_OVR]
set_input_delay -clock ADC_DCO -min 0.5 [get_ports ADC_OVR]
```

### 1.4 延迟值计算方法

#### 1.4.1 基本计算公式

```
最大输入延迟 = 外部设备最大 Tco + 最大 PCB 布线延迟 + 封装延迟
最小输入延迟 = 外部设备最小 Tco + 最小 PCB 布线延迟 + 封装延迟
```

#### 1.4.2 详细计算示例

**外部芯片参数**：
- Tco_max = 3.0ns（时钟到输出最大延迟）
- Tco_min = 1.0ns（时钟到输出最小延迟）

**PCB 布线延迟**：
- 走线长度：5cm
- 介电常数：4.2
- 传播速度：约 14.3cm/ns
- 布线延迟：5cm / 14.3cm/ns ≈ 0.35ns
- 考虑工艺偏差：±20%，即 0.28ns ~ 0.42ns

**封装延迟**：
- FPGA 封装延迟：0.1ns ~ 0.2ns
- 外部芯片封装延迟：0.05ns ~ 0.15ns

**最终计算**：
```tcl
# 最大输入延迟 = 3.0 + 0.42 + 0.2 + 0.15 = 3.77ns ≈ 3.8ns
# 最小输入延迟 = 1.0 + 0.28 + 0.1 + 0.05 = 1.43ns ≈ 1.4ns

set_input_delay -clock REF_CLK -max 3.8 [get_ports INPUT_SIGNALS[*]]
set_input_delay -clock REF_CLK -min 1.4 [get_ports INPUT_SIGNALS[*]]
```

#### 1.4.3 不同接口类型的典型值

| 接口类型 | 频率范围 | 典型最大延迟 | 典型最小延迟 | 备注 |
|---------|---------|-------------|-------------|------|
| 低速 GPIO | < 10MHz | 5-10ns | 1-2ns | 包含较大的布线延迟 |
| 中速并行总线 | 10-100MHz | 2-5ns | 0.5-1ns | 如 CPU 接口 |
| 高速串行接口 | > 100MHz | 1-2ns | 0.1-0.3ns | 如 LVDS、ADC |
| 同步存储器接口 | 100-400MHz | 1.5-3ns | 0.2-0.8ns | 如 SRAM、SDRAM |

### 1.5 高级输入延迟约束

#### 1.5.1 时钟边沿相关约束

```tcl
# 上升沿和下降沿分别约束（DDR 接口）
set_input_delay -clock DDR_CLK -max 2.0 -clock_fall [get_ports DDR_DQ[*]]
set_input_delay -clock DDR_CLK -min 0.5 -clock_fall [get_ports DDR_DQ[*]]

set_input_delay -clock DDR_CLK -max 1.8 [get_ports DDR_DQ[*]]
set_input_delay -clock DDR_CLK -min 0.3 [get_ports DDR_DQ[*]]
```

#### 1.5.2 添加模式约束

```tcl
# 为同一端口的不同工作模式设置不同延迟
set_input_delay -clock CLK_MODE1 -max 3.0 [get_ports MULTI_MODE_DATA[*]]
set_input_delay -clock CLK_MODE1 -min 1.0 [get_ports MULTI_MODE_DATA[*]]

set_input_delay -clock CLK_MODE2 -max 2.5 [get_ports MULTI_MODE_DATA[*]] -add_delay
set_input_delay -clock CLK_MODE2 -min 0.8 [get_ports MULTI_MODE_DATA[*]] -add_delay
```

## 2. 输出延迟约束（Output Delay）

### 2.1 核心概念

**输出延迟（Output Delay）** 用于描述 FPGA 输出信号到达外部设备输入端口的延迟范围，相对于参考时钟的时序关系，确保外部设备有足够的建立/保持时间来正确采样 FPGA 的输出信号。

### 2.2 作用机制

输出延迟约束告诉时序分析工具：
- **FPGA 输出信号从参考时钟的有效沿到外部设备输入端口的延迟范围**
- **确保外部设备有足够的建立/保持时间**
- **优化 FPGA 内部到输出端口的时序路径**

### 2.3 应用场景详解

#### 2.3.1 DAC 数据输出

**场景描述**：FPGA 向 14 位 125MSPS DAC 输出数据。

```tcl
# 创建虚拟时钟模拟 DAC 采样时钟（125MHz）
create_clock -name VIRT_DAC_CLK -period 8.0

# 设置 DAC 数据输出延迟
set_output_delay -clock VIRT_DAC_CLK -max 4.0 [get_ports DAC_DATA[*]]
set_output_delay -clock VIRT_DAC_CLK -min 1.0 [get_ports DAC_DATA[*]]

# 设置 DAC 控制信号输出延迟
set_output_delay -clock VIRT_DAC_CLK -max 3.5 [get_ports {DAC_WR DAC_CLK}]
set_output_delay -clock VIRT_DAC_CLK -min 0.8 [get_ports {DAC_WR DAC_CLK}]
```

#### 2.3.2 LCD 显示接口

**场景描述**：FPGA 向 LCD 控制器输出 RGB 数据和控制信号。

```tcl
# 创建 LCD 像素时钟（65MHz）
create_clock -name LCD_PCLK -period 15.38 [get_ports LCD_PCLK]

# 设置 RGB 数据输出延迟
set_output_delay -clock LCD_PCLK -max 2.5 [get_ports LCD_RGB[*]]
set_output_delay -clock LCD_PCLK -min -0.5 [get_ports LCD_RGB[*]]

# 设置同步信号输出延迟
set_output_delay -clock LCD_PCLK -max 2.0 [get_ports {LCD_HSYNC LCD_VSYNC LCD_DE}]
set_output_delay -clock LCD_PCLK -min -0.3 [get_ports {LCD_HSYNC LCD_VSYNC LCD_DE}]
```

#### 2.3.3 外部存储器接口

**场景描述**：FPGA 向外部 SRAM 输出地址、数据和控制信号。

```tcl
# 定义存储器时钟（100MHz）
create_clock -name MEM_CLK -period 10.0 [get_ports MEM_CLK]

# 设置地址信号输出延迟
set_output_delay -clock MEM_CLK -max 3.0 [get_ports MEM_ADDR[*]]
set_output_delay -clock MEM_CLK -min 0.5 [get_ports MEM_ADDR[*]]

# 设置数据信号输出延迟
set_output_delay -clock MEM_CLK -max 2.8 [get_ports MEM_DATA[*]]
set_output_delay -clock MEM_CLK -min 0.3 [get_ports MEM_DATA[*]]

# 设置控制信号输出延迟
set_output_delay -clock MEM_CLK -max 2.5 [get_ports {MEM_WE MEM_OE MEM_CS}]
set_output_delay -clock MEM_CLK -min 0.8 [get_ports {MEM_WE MEM_OE MEM_CS}]
```

### 2.4 延迟值计算方法

#### 2.4.1 基本计算公式

```
最大输出延迟 = PCB 最大布线延迟 + 外部设备建立时间要求 + 封装延迟
最小输出延迟 = PCB 最小布线延迟 - 外部设备保持时间要求 + 封装延迟
```

#### 2.4.2 详细计算示例

**外部设备参数**（以 SRAM 为例）：
- Tsu = 2.0ns（建立时间要求）
- Th = 1.0ns（保持时间要求）

**PCB 布线延迟**：
- 走线长度：3cm
- 布线延迟：3cm / 14.3cm/ns ≈ 0.21ns
- 考虑工艺偏差：±15%，即 0.18ns ~ 0.24ns

**封装延迟**：
- FPGA 输出封装延迟：0.1ns ~ 0.15ns
- 外部设备输入封装延迟：0.05ns ~ 0.1ns

**最终计算**：
```tcl
# 最大输出延迟 = 0.24 + 2.0 + 0.15 + 0.1 = 2.49ns ≈ 2.5ns
# 最小输出延迟 = 0.18 - 1.0 + 0.1 + 0.05 = -0.67ns ≈ -0.7ns

set_output_delay -clock MEM_CLK -max 2.5 [get_ports MEM_SIGNALS[*]]
set_output_delay -clock MEM_CLK -min -0.7 [get_ports MEM_SIGNALS[*]]
```

#### 2.4.3 负延迟的含义

负的最小输出延迟表示：
- **FPGA 输出信号可以在参考时钟沿之前变化**
- **为外部设备提供更多的保持时间余量**
- **常见于高速接口或保持时间要求较严格的场景**

### 2.5 高级输出延迟约束

#### 2.5.1 双边沿约束

```tcl
# DDR 输出接口（上升沿和下降沿都传输数据）
set_output_delay -clock DDR_CLK -max 1.5 [get_ports DDR_DQ[*]]
set_output_delay -clock DDR_CLK -min -0.5 [get_ports DDR_DQ[*]]

set_output_delay -clock DDR_CLK -max 1.3 -clock_fall [get_ports DDR_DQ[*]]
set_output_delay -clock DDR_CLK -min -0.3 -clock_fall [get_ports DDR_DQ[*]]
```

#### 2.5.2 多目标约束

```tcl
# 同一信号连接到多个外部设备
set_output_delay -clock CLK_DEV1 -max 3.0 [get_ports SHARED_SIGNAL]
set_output_delay -clock CLK_DEV1 -min 0.5 [get_ports SHARED_SIGNAL]

set_output_delay -clock CLK_DEV2 -max 2.5 [get_ports SHARED_SIGNAL] -add_delay
set_output_delay -clock CLK_DEV2 -min 0.8 [get_ports SHARED_SIGNAL] -add_delay
```

## 3. 双向信号约束

### 3.1 双向信号特点

双向信号（如三态总线）需要同时设置输入和输出延迟约束，因为信号可能在不同时刻作为输入或输出使用。

### 3.2 约束示例

#### 3.2.1 双向数据总线

```tcl
# 定义双向总线时钟
create_clock -name BUS_CLK -period 10.0 [get_ports BUS_CLK]

# 设置输入延迟（当作为输入时）
set_input_delay -clock BUS_CLK -max 2.5 [get_ports BIDIR_DATA[*]]
set_input_delay -clock BUS_CLK -min 0.5 [get_ports BIDIR_DATA[*]]

# 设置输出延迟（当作为输出时）
set_output_delay -clock BUS_CLK -max 3.0 [get_ports BIDIR_DATA[*]]
set_output_delay -clock BUS_CLK -min 0.3 [get_ports BIDIR_DATA[*]]

# 设置方向控制信号
set_output_delay -clock BUS_CLK -max 2.0 [get_ports BUS_DIR]
set_output_delay -clock BUS_CLK -min 0.8 [get_ports BUS_DIR]
```

#### 3.2.2 I2C 接口

```tcl
# I2C 时钟（100kHz）
create_clock -name I2C_CLK -period 10000 [get_ports SCL]

# SDA 双向信号约束
set_input_delay -clock I2C_CLK -max 1000 [get_ports SDA]
set_input_delay -clock I2C_CLK -min 100 [get_ports SDA]

set_output_delay -clock I2C_CLK -max 1200 [get_ports SDA]
set_output_delay -clock I2C_CLK -min 200 [get_ports SDA]

# SCL 输出约束
set_output_delay -clock I2C_CLK -max 1000 [get_ports SCL]
set_output_delay -clock I2C_CLK -min 300 [get_ports SCL]
```

```tcl
# 仅在使能信号有效时约束
set_input_delay -clock REF_CLK -max 2.0 [get_ports DATA[*]]
```

## 5. 常见问题与解决方案

### 5.1 约束冲突问题

#### 5.1.1 多时钟约束冲突

**问题**：同一信号被多个时钟约束，导致冲突。

```tcl
# 错误示例
set_input_delay -clock CLK1 -max 2.0 [get_ports DATA]
set_input_delay -clock CLK2 -max 1.5 [get_ports DATA]  # 冲突！

# 正确做法：使用 -add_delay
set_input_delay -clock CLK1 -max 2.0 [get_ports DATA]
set_input_delay -clock CLK2 -max 1.5 [get_ports DATA] -add_delay
```

#### 5.1.2 约束覆盖问题

**问题**：后定义的约束覆盖了前面的约束。

```tcl
# 问题示例
set_input_delay -clock CLK -max 2.0 [get_ports DATA[*]]
set_input_delay -clock CLK -max 1.5 [get_ports DATA[0]]  # 覆盖了上面的约束

# 解决方案：明确约束范围
set_input_delay -clock CLK -max 2.0 [get_ports DATA[7:1]]
set_input_delay -clock CLK -max 1.5 [get_ports DATA[0]]
```

### 5.2 时序收敛问题

#### 5.2.1 建立时间违规

**问题分析**：输入延迟过大，导致内部路径建立时间不足。

**解决方案**：
```tcl
# 1. 减小最大输入延迟
set_input_delay -clock CLK -max 1.5 [get_ports DATA[*]]  # 原来是 2.5

# 2. 增加时钟周期（降低频率）
create_clock -name CLK -period 12.0 [get_ports CLK]  # 原来是 10.0

# 3. 使用多周期路径
set_multicycle_path 2 -setup -from [get_ports DATA[*]]
```

#### 5.2.2 保持时间违规

**问题分析**：最小输入延迟过小，导致保持时间不足。

**解决方案**：
```tcl
# 1. 增加最小输入延迟
set_input_delay -clock CLK -min 1.0 [get_ports DATA[*]]  # 原来是 0.2

# 2. 添加最小延迟约束
set_min_delay 0.5 -from [get_ports DATA[*]] -to [get_registers input_reg[*]/D]

# 3. 调整时钟偏移
set_clock_uncertainty -hold 0.2 [get_clocks CLK]
```

### 5.3 约束验证问题

#### 5.3.1 约束检查命令

```tcl
# 检查输入延迟约束
report_input_delay -verbose

# 检查输出延迟约束
report_output_delay -verbose

# 检查约束覆盖情况
report_exceptions -ignored

# 检查时序路径
report_timing -from [get_ports INPUT[*]] -max_paths 10
```

#### 5.3.2 约束调试技巧

```tcl
# 临时移除约束进行测试
set_input_delay -clock CLK -max 0 [get_ports TEST_PORT]
set_input_delay -clock CLK -min 0 [get_ports TEST_PORT]

# 使用宽松约束进行初步验证
set_input_delay -clock CLK -max 10.0 [get_ports DATA[*]]
set_input_delay -clock CLK -min -5.0 [get_ports DATA[*]]

# 逐步收紧约束
# 第一轮：宽松约束
# 第二轮：中等约束
# 第三轮：最终约束
```

## 6. 最佳实践

### 6.1 约束编写原则

#### 6.1.1 分层约束策略

```tcl
# 1. 首先定义时钟
create_clock -name SYS_CLK -period 10.0 [get_ports sys_clk]
create_clock -name VIRT_EXT_CLK -period 8.0

# 2. 设置输入延迟约束
```
