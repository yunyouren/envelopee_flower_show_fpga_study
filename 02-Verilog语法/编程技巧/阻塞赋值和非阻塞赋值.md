#阻塞赋值
### 阻塞赋值

- **符号**：使用 “=” 进行赋值。
- **执行特点**：在语句执行时，先计算等号右侧表达式的值，然后==立即将该值赋给左侧变量==。在该语句执行完成之前，后续语句不会执行，就好像该语句 “阻塞” 了程序的执行流程一样。
- **应用场景**：常用于组合逻辑电路的描述，因为组合逻辑的输出只取决于当前的输入，不需要考虑时序问题，阻塞赋值能够按照顺序依次计算和更新变量的值，符合组合逻辑的工作原理。
- **示例**
  
```verilog
module blocking_assign_example;
    reg a, b, c;
    initial begin
        a = 1'b0;
        b = 1'b1;
        c = a + b; // 先计算a + b，然后将结果赋给c，此时c的值为1
        $display("c = %b", c);
    end
endmodule
```

#非阻塞赋值
### 非阻塞赋值

- **符号**：使用 “<=” 进行赋值。
- **执行特点**：在语句执行时，先计算等号右侧表达式的值，但并不立即将该值赋给左侧变量，而是将这个==赋值操作安排在当前时间步的末尾进行==。在当前时间步内，其他语句可以继续执行，不会被阻塞。这意味着在同一个时间步内，多个非阻塞赋值语句可以并发执行，它们之间的执行顺序不会影响最终的结果。
- **应用场景**：主要用于时序逻辑电路的描述，如寄存器、触发器等。在时序电路中，需要按照时钟信号的节拍来更新寄存器的值，非阻塞赋值能够确保在一个时钟周期内，所有的寄存器更新操作都在同一时刻（时钟上升沿或下降沿）进行，避免了竞争冒险等问题。
```verilog
module nonblocking_assign_example;
    reg a, b, c;
    initial begin
        a = 1'b0;
        b = 1'b1;
        c <= a + b; // 计算a + b，但不立即赋值给c
        // 此时可以执行其他语句，假设这里有其他操作
        $display("c = %b", c); // 这里输出的c值还是初始值，因为非阻塞赋值还未执行
        #1; // 等待一个时间单位
        $display("c = %b", c); // 此时c的值才被更新为1
    end
endmodule
```


组合逻辑中，使用阻塞赋值可以清晰地描述逻辑运算的顺序；而在时序逻辑中，非阻塞赋值能够准确地模拟寄存器等时序元件的行为




#input`

- **功能**：用于声明模块的输入端口，即外部信号进入模块的接口。
- **特点**
    - 模块只能从 `input` 端口接收数据，不能向其发送数据。
    - `input` 端口通常连接到外部的驱动源，如其他模块的输出、时钟信号或控制信号等。
    - 它可以是标量（单个位）或向量（多位）信号。
- **示例**

```verilog
module my_module(
    input clk,       // 时钟信号输入
    input [7:0] data // 8位数据输入
);
// 模块内部使用输入信号进行逻辑处理
endmodule
```

#inout`

- **功能**：用于声明模块的双向端口，既可以作为输入端口接收外部数据，也可以作为输出端口向外部发送数据。
- **特点**
    - `inout` 端口需要额外的逻辑来控制数据的流向，通常通过三态缓冲器或其他控制信号来实现。
    - 在同一时刻，`inout` 端口只能作为输入或输出，不能同时进行输入和输出操作。
    - 它也可以是标量或向量信号。
- **示例**

```verilog
module bidirectional_module(
    inout [7:0] bus,   // 双向数据总线
    input write_en,    // 写使能信号
    input read_en      // 读使能信号
);
reg [7:0] internal_data;

// 写操作逻辑
always @(posedge write_en) begin
    internal_data <= bus;
end

// 读操作逻辑
always @(posedge read_en) begin
    bus <= internal_data;
end

endmodule
```

  

`input` 和 `inout` 端口在模块的接口定义中起着不同的作用，根据具体的设计需求选择合适的端口类型来实现模块之间的数据交互。
