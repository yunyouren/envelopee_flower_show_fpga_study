### 🔍 时序问题诊断流程
1. **检查约束覆盖率** → [约束验证与调试](/05-%E6%97%B6%E5%BA%8F%E7%BA%A6%E6%9D%9F/02-%E5%B7%A5%E5%85%B7%E5%88%86%E6%9E%90/%E7%BA%A6%E6%9D%9F%E9%AA%8C%E8%AF%81%E4%B8%8E%E8%B0%83%E8%AF%95.md#)
2. **分析时序报告** → 识别违规路径
3. **确定优化策略** → RTL优化 vs 约束调整
4. **实施优化方案** → [优化策略](03-优化策略/)
5. **验证优化效果** → 重新分析时序

### 时序优化检查清单
- [ ] 时钟约束是否完整？

- [ ] 关键路径是否需要流水线？
- [ ] 扇出是否过大？
- [ ] 是否存在组合逻辑环路？
- [ ] I/O约束是否准确？
- [ ] 物理约束是否合理？

## 🎯 学习建议

### 📚 学习策略
1. **循序渐进**：按照学习路径顺序进行，重点掌握⭐⭐⭐级别内容
2. **理论结合实践**：每学完一个约束类型，立即在项目中尝试应用
3. **多做笔记**：记录遇到的问题和解决方案，建立个人知识库
4. **定期复习**：时序约束是需要反复练习的技能，建议每月回顾

### 🛠️ 实践建议
- **从简单项目开始**：先在简单设计上练习约束编写
- **使用检查清单**：每次编写约束时对照检查清单
- **分析时序报告**：养成仔细分析时序报告的习惯
- **记录优化过程**：记录每次时序优化的前后对比

### 📖 推荐学习顺序
1. 先学习 **基础入门** 建立概念基础
2. 重点学习 **约束类型专门指南**（时钟→I/O→例外→物理）
3. 掌握 **验证与调试** 技能
4. 学习 **最佳实践** 提升工程能力
5. 通过 **项目实践** 巩固技能
