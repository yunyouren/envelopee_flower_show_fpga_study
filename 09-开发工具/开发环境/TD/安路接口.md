# 将所有未使用引脚保留下拉（PULLDOWN）状态
**核心配置：`PULLDOWN`**

- **效果：** 为所有未使用的 I/O 引脚**启用内部弱下拉电阻**。这会将引脚的电平**稳定地拉向地（GND / 逻辑 0）**，防止其悬空。
    
- **目的：** 避免悬空引脚导致的功耗增加、噪声干扰、系统不稳定甚至潜在损坏风险。
    

**其他选项解析：**

1. **`PULLUP`：**
    
    - **效果：** 启用内部弱上拉电阻，将引脚电平拉向电源（VCCIO / 逻辑 1）。
        
    - **与要求匹配度：❌ 不匹配**。您明确要求的是下拉（PULLDOWN），不是上拉（PULLUP）。
        
2. **`PULLDOWN`：**
    
    - **效果：** 如上所述，启用内部弱下拉电阻。
        
    - **与要求匹配度：✅ 完全匹配**。这是您指定的状态。
        
3. **`KEEPER`：**
    
    - **效果：** 启用“总线保持”电路（Bus Keeper）。它不是一个电阻，而是一个弱驱动电路，**试图保持引脚上一次已知的逻辑状态**（0 或 1）。如果引脚之前没有被驱动过，状态不确定。
        
    - **与要求匹配度：❌ 不匹配**。它不提供固定的下拉状态（PULLDOWN），状态可能不确定或随噪声变化。
        
4. **`NE`：**
    
    - **效果：** **无效果**（No Effect）。引脚完全悬空（高阻态输入）。这是**最不推荐**的做法，会导致所有悬空引脚的问题。
        
    - **与要求匹配度：❌ 不匹配**。它完全违背了您“保留在指定状态（下拉）”的要求。
