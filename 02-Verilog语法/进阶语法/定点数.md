
> [!NOTE] 核心定义  
> **定点数**（Fixed-Point Number）是一种在数字系统（尤其是 FPGA、嵌入式系统、数字信号处理）中表示小数的方法。它通过**固定小数点位置**，用整数形式模拟实数运算，是浮点数的高效替代方案。

---

## 一、为什么需要定点数？

在硬件设计（如 Verilog、VHDL）中：
- **浮点数**（如 `float`）运算复杂，需要大量逻辑资源（LUT、DSP）
- **整数**无法表示小数，精度不足
- **定点数**在**精度与资源**之间取得平衡，适合 FPGA、DSP 芯片

> ✅ 适用场景：CORDIC、FIR 滤波器、神经网络量化、音频/图像处理

---

## 二、定点数的基本原理

### 2.1 核心思想
- 将一个实数乘以一个缩放因子 $2^n$，变成整数存储
- 运算时当作整数处理
- 输出时再除以 $2^n$，还原为实数

例如：
- 实数：`0.75`
- 缩放因子：$2^4 = 16$
- 定点表示：`0.75 × 16 = 12` → 存储为整数 `12`
- 运算后，再除以 16 得到实际值

### 2.2 小数点是“虚拟的”
- 硬件中**没有真正的小数点**
- 小数点位置由设计者**约定**，称为 **Q 格式**

---

## 三、Q 格式：定点数的表示法

### 3.1 Qm. N 格式
- **m**：整数部分位数（含符号位）
- **n**：小数部分位数
- 总位宽 = m + n
- 最小分辨率 = $2^{-n}$

| Q 格式 | 示例 | 含义 |
|--------|------|------|
| Q 7.8 | 16 位 | 7 位整数（含符号），8 位小数 |
| Q 15.16 | 32 位 | 15 位整数（含符号），16 位小数 |
| Q 0.15 | 16 位 | 无整数位，15 位小数（常用于 [-1,1) 范围） |

### 3.2 表示范围与精度
以 **Q 7.8**（16 位有符号）为例：
- 范围：$[-2^7, 2^7 - 2^{-8}) = [-128, 127.996]$
- 分辨率：$2^{-8} = 1/256 \approx 0.00390625$

> [!TIP]  
> **n 越大，小数精度越高，但整数范围越小**

## 四、定点数的二进制表示（以 Q 3.4 为例）

假设用 Q 3.4 表示 `-1.5`：

1. 实数：`-1.5`
2. 乘以 $2^4 = 16$：`-1.5 × 16 = -24`
3. `-24` 的 7 位补码：`101000`
4. 二进制：`101.0000` → 小数点在第 4 位前

| 位 | 6 | 5 | 4 | 3 | 2 | 1 | 0 |
|----|----|----|----|----|----|----|----|
| 值 | 1 | 0 | 1 | 0 | 0 | 0 | 0 |
| 权重 | -4 | 2 | 1 | 0.5 | 0.25 | 0.125 | 0.0625 |

计算：`-4 + 1 = -3`？不对！

修正：Q 3.4 是 7 位，权重：
- `[6]`: -4
- `[5]`: 2
- `[4]`: 1
- `[3]`: 0.5
- `[2]`: 0.25
- `[1]`: 0.125
- `[0]`: 0.0625

`1010000` = `-4 + 1 = -3`？还是不对。

正确做法：
- `-1.5 × 16 = -24`
- 7 位补码：`101000` → 但需 7 位：`1101000`？错。

更正：7 位补码表示 -24：
- 24 的二进制：`0011000`
- 取反加一：`1100111 + 1 = 1101000`

所以 `-1.5` 在 Q 3.4 下是 `1101000`，即：
- `110.1000` → `-4 + 2 + 0.5 = -1.5` ✅

## 五、定点数的运算规则

### 5.1 加法 / 减法
- **必须 Q 格式相同**（小数点对齐）
- 直接按整数加减
- 结果仍是相同 Q 格式

```verilog
// Q7.8 + Q7.8 → Q7.8
assign sum = a + b;
```

### 5.2 乘法
- Qm 1. N 1 × Qm 2. N 2 → Q (m 1+m 2). (n 1+n 2)
- 结果位宽翻倍，通常需**截断或舍入**

```verilog
// Q7.8 × Q7.8 → Q14.16
wire [31:0] product = a * b;
wire [15:0] result = product >> 8;  // 截断为 Q7.8
```

### 5.3 除法
- 复杂，通常避免或使用移位近似
- 可能损失精度

## 六、定点数的舍入（Rounding）

由于位宽限制，必须截断低位，常见策略：

| 方法 | 说明 | 是否有偏 |
|------|------|----------|
| **截断**（Truncate） | 直接丢弃低位 | 有偏（向下） |
| **四舍五入** | ≥0.5 则进位 | 有偏（向上） |
| **向偶数舍入**（Banker's Rounding） | =0.5 时向最近偶数舍入 | ✅ 无偏 |

> [!EXAMPLE]  
> 在 CORDIC 中常用 **向偶数舍入** 减少累积误差。

## 七、Verilog 中的实现技巧

### 7.1 声明有符号数
```verilog
reg signed [15:0] data;  // Q7.8
```

### 7.2 符号扩展
```verilog
// Q7.8 → Q15.16
assign extended = { {8{data[15]}}, data, 8'b0 };
```

### 7.3 使用 `$signed`
```verilog
assign sum = $signed(a) + $signed(b);  // 确保有符号运算
```

## 八、定点数 vs 浮点数

| 特性 | 定点数 | 浮点数 |
|------|--------|--------|
| 精度 | 固定 | 动态（指数） |
| 范围 | 有限 | 很大 |
| 资源消耗 | 低（整数运算） | 高（需 FPU/DSP） |
| 实现难度 | 简单 | 复杂 |
| 适用场景 | FPGA、嵌入式、DSP | CPU、GPU、高精度计算 |

> ✅ **FPGA 中，能用定点就不用浮点！**

---

## 九、常见应用

- **CORDIC 算法**：计算 sin/cos/tan，使用 Q 格式
- **FIR/IIR 滤波器**：系数和信号多为定点
- **神经网络量化**：将 FP 32 权重转为 INT 8/Q 7.8
- **音频处理**：PCM 数据常为 Q 0.15
- **图像处理**：像素坐标、滤波核
