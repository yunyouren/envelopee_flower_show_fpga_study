# Verilog模块化设计

## 📖 模块基础概念

### 什么是模块
模块(Module)是Verilog中最基本的设计单元，类似于C语言中的函数。每个模块都有：
- **模块名称** - 唯一标识符
- **端口列表** - 输入输出接口
- **内部逻辑** - 功能实现

### 基本语法结构
```verilog
module 模块名 (
    input  [位宽-1:0] 输入端口名,
    output [位宽-1:0] 输出端口名
);

// 内部信号声明
wire/reg [位宽-1:0] 内部信号;

// 逻辑实现
// ...

endmodule
```

## 🔌 端口声明

### 端口类型
- **input** - 输入端口
- **output** - 输出端口  
- **inout** - 双向端口

### 端口声明方式

#### 方式一：ANSI-C风格（推荐）
```verilog
module counter (
    input        clk,
    input        rst_n,
    input        en,
    output [7:0] count
);
```

#### 方式二：传统风格
```verilog
module counter (clk, rst_n, en, count);
    input        clk;
    input        rst_n;
    input        en;
    output [7:0] count;
```

## 🔗 模块实例化

### 实例化语法
```verilog
模块名 实例名 (
    .端口名(连接信号),
    .端口名(连接信号)
);
```

### 实例化示例
```verilog
// 定义一个简单的与门模块
module and_gate (
    input  a,
    input  b,
    output y
);
    assign y = a & b;
endmodule

// 在顶层模块中实例化
module top_module (
    input  in1,
    input  in2,
    output out
);
    
    and_gate u_and (
        .a(in1),
        .b(in2),
        .y(out)
    );
    
endmodule
```

## 📊 参数传递

### 参数定义
```verilog
module counter #(
    parameter WIDTH = 8,
    parameter MAX_COUNT = 255
)(
    input                clk,
    input                rst_n,
    output [WIDTH-1:0]   count
);

reg [WIDTH-1:0] count_reg;

always @(posedge clk or negedge rst_n) begin
    if (!rst_n)
        count_reg <= 0;
    else if (count_reg == MAX_COUNT)
        count_reg <= 0;
    else
        count_reg <= count_reg + 1;
end

assign count = count_reg;

endmodule
```

### 参数传递
```verilog
// 实例化时传递参数
counter #(
    .WIDTH(16),
    .MAX_COUNT(65535)
) u_counter16 (
    .clk(clk),
    .rst_n(rst_n),
    .count(count16)
);
```

## 🏗️ 设计实例

### 完整的模块化设计示例
```verilog
// 4位全加器模块
module full_adder_4bit (
    input  [3:0] a,
    input  [3:0] b,
    input        cin,
    output [3:0] sum,
    output       cout
);

wire [3:0] carry;

full_adder u0 (.a(a[0]), .b(b[0]), .cin(cin),     .sum(sum[0]), .cout(carry[0]));
full_adder u1 (.a(a[1]), .b(b[1]), .cin(carry[0]), .sum(sum[1]), .cout(carry[1]));
full_adder u2 (.a(a[2]), .b(b[2]), .cin(carry[1]), .sum(sum[2]), .cout(carry[2]));
full_adder u3 (.a(a[3]), .b(b[3]), .cin(carry[2]), .sum(sum[3]), .cout(carry[3]));

assign cout = carry[3];

endmodule

// 1位全加器模块
module full_adder (
    input  a,
    input  b,
    input  cin,
    output sum,
    output cout
);

assign {cout, sum} = a + b + cin;

endmodule
```

## 💡 设计技巧

### 1. 命名规范
- **模块名**: 小写字母，下划线分隔
- **实例名**: u_ 前缀 + 功能描述
- **端口名**: 简洁明了，体现功能

### 2. 模块划分原则
- **功能单一**: 每个模块只完成一个特定功能
- **接口清晰**: 端口定义明确，易于理解
- **可重用性**: 设计通用性强的模块

### 3. 层次化设计
```
顶层模块 (top_module)
├── 控制模块 (control_unit)
├── 数据通路 (datapath)
│   ├── ALU模块 (alu)
│   ├── 寄存器组 (register_file)
│   └── 多路选择器 (mux)
└── 存储器接口 (memory_interface)
```

## ⚠️ 常见错误

### 1. 端口连接错误
```verilog
// 错误：位宽不匹配
wire [7:0] data_8bit;
wire [15:0] data_16bit;

module_8bit u1 (.data(data_16bit)); // 位宽不匹配

// 正确：位宽匹配
module_8bit u1 (.data(data_8bit));
```

### 2. 未连接的端口
```verilog
// 错误：输出端口未连接
module_name u1 (
    .clk(clk),
    .rst_n(rst_n)
    // .output_port() 忘记连接输出端口
);

// 正确：所有端口都要连接
module_name u1 (
    .clk(clk),
    .rst_n(rst_n),
    .output_port(output_signal)
);
```
