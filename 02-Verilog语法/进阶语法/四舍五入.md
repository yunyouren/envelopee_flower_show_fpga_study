**“向最接近偶数舍入”（Round to Nearest Even）**，也称为 **银行家舍入法（Banker's Rounding）**，是数字信号处理（如 CORDIC 算法）中常用的高精度舍入策略，用于**减少长期累积的量化偏差**。

---

## 🔍 代码解析：向偶数舍入的 Verilog 实现

```verilog
wire [(WW-1):0] pre_xval, pre_yval;    // 舍入前的中间结果

// 舍入逻辑：向偶数舍入（银行家舍入法）
assign pre_xval = xv[NSTAGES] + $signed({
    {(OW){1'b0}},                           // [1] 高位补零（占位）
    xv[NSTAGES][(WW-OW)],                   // [2] 检查“舍入位”（guard bit）
    {(WW-OW-1){ !xv[NSTAGES][WW-OW] }}      // [3] 填充“粘滞位”（sticky bits）
});
```

### 参数说明
- `WW`：**工作位宽**（Working Width），如 32 位（高精度中间计算）
- `OW`：**输出位宽**（Output Width），如 16 位（最终输出）
- `NSTAGES`：CORDIC 迭代总级数，`xv[NSTAGES]` 是最终未舍入的结果
- 目标：将 `WW` 位的 `xv[NSTAGES]` 舍入为 `OW` 位，**保留高精度的同时减少偏差**

---

## 🧠 核心思想：什么是“向偶数舍入”？

在定点数截断时，若被舍去的部分 **正好是 0.5**（即二进制 `0.100...0`），传统“四舍五入”总是向上取整，会导致**长期统计偏差**（偏向正数）。

而 **向偶数舍入** 规则如下：

| 被舍去部分 | 动作 |
|------------|------|
| < 0.5      | 向下舍入（截断） |
| > 0.5      | 向上舍入（+1） |
| = 0.5      | **舍入到最近的偶数** |

✅ 优点：长期统计无偏，广泛用于 IEEE 754 浮点、高精度 DSP。

---

## 🛠️ 这段代码如何实现“向偶舍入”？

我们来拆解加法的第二项：

```verilog
$signed({
    {(OW){1'b0}},                           // A
    xv[NSTAGES][(WW-OW)],                   // B
    {(WW-OW-1){ !xv[NSTAGES][WW-OW] }}      // C
})
```

这实际上是在构造一个 **“舍入偏移量”（rounding bias）**，加到原始值上，再截断低 `(WW-OW)` 位。

### 分步解释：

| 部分 | 位数 | 含义 |
|------|------|------|
| A: `{(OW){1'b0}}` | `OW` 位 | 高位为 0，不影响结果 |
| B: `xv[NSTAGES][(WW-OW)]` | 1 位 | **“保护位”（Guard bit）**，即第 `OW` 位（将被舍去的第一位） |
| C: `{(WW-OW-1){ !xv[...][WW-OW] }}` | `WW-OW-1` 位 | **“粘滞位”（Sticky bits）**：若任何低位为 1，则 sticky=1 |

> 💡 Guard bit + Sticky bit 构成了判断“是否 ≥ 0.5”的依据。

---

### 关键：构造“粘滞位”的技巧

```verilog
{(WW-OW-1){ !xv[NSTAGES][WW-OW] }}
```

这个表达式有点反直觉，我们来分析其行为：

| Guard bit `g = xv[WW-OW]` | 粘滞位填充值 | 实际 sticky 值（是否非零） |
|---------------------------|--------------|----------------------------|
| `g = 1`（Guard=1）        | 填 `0` s      | sticky = 0 → 表示低位全 0 → 正好是 0.5 |
| `g = 0`（Guard=0）        | 填 `1` s      | sticky = 1 → 表示低位有 1 → 大于 0.5 |

> ⚠️ 注意：这是个巧妙的“反逻辑”设计！

- 当 `g=1` 时，我们**希望 sticky=0**（表示正好 0.5），所以填 `0`
- 当 `g=0` 时，我们**希望 sticky=1**（表示 >0.5），所以填 `1`

但实际上：
- **真正的 sticky bit** 应该是：`| xv[NSTAGES][WW-OW-1:0]`（所有低位的或）
- 但这里用 `!g` 作为填充，是一种**近似或保守估计**，在某些实现中可接受。

> ✅ 更标准的 sticky bit 写法应为：
> ```verilog
> wire sticky = | xv[NSTAGES][WW-OW-1:0];
> assign rounding_bias = { {(OW+1){1'b0}}, xv[NSTAGES][WW-OW], sticky };
> ```

但你的代码用 `!g` 作为 sticky 的代理，是一种**简化实现**，假设：
- 如果 `g=1`，且我们填 `0`，则总偏移 = `0.5`
- 如果 `g=0`，我们填 `1` s，则总偏移 > `0.5`，触发进位

---

## 📊 舍入行为分析

设我们要保留高 `OW` 位，舍去低 `WW-OW` 位。

| 情况 | Guard | Sticky | 偏移量 | 动作 | 是否符合向偶舍入？ |
|------|-------|--------|--------|------|------------------|
| < 0.5 | 0 | 0 | 0 | 截断 | ✅ |
| = 0.5 | 1 | 0 | +0.5 | **进位？不一定** | ❌ 不完全 |
| > 0.5 | 1 | 1 或 0（但 `g=0` 时填 1） | ≥ +0.5 | 进位 | ✅ |

> ⚠️ 问题：当 `g=1` 且低位全 0（正好 0.5）时，偏移 = `0.5`，加完后可能进位，**但未检查“向偶”条件**！

所以：
- 这段代码**实现了“四舍五入”或“向上舍入”**，但**并未真正实现“向偶数舍入”**
- 它缺少对 **“进位后结果是否为偶数”** 的判断

---

## ✅ 真正的“向偶数舍入”应该如何实现？

```verilog
// 正确的向偶舍入（Round to Nearest Even）
function [WW-1:0] round_to_even;
    input [WW-1:0] in;
    reg [OW-1:0]   result;
    reg            guard, sticky, lsb;
    
    begin
        guard   = in[WW-OW];                    // 保护位
        sticky  = | in[WW-OW-1:0];              // 粘滞位（任意低位为1）
        lsb     = in[WW-OW+1];                  // 最低保留位
        
        if (guard && (sticky || lsb))           // > 0.5 或 (=0.5 且 lsb=1)
            result = in[WW-1 : WW-OW] + 1;      // 进位
        else
            result = in[WW-1 : WW-OW];          // 截断
        round_to_even = {result, {(WW-OW){1'b0}}};
    end
endfunction
```

---

### 作用
- 在截断前添加一个**舍入偏移量**，实现近似“四舍五入”
- 利用 `guard bit` 和 `sticky bit` 判断是否进位

### 问题
- **未真正实现“向偶数舍入”**，缺少对 LSB 的判断
- `sticky` 位用 `!guard` 近似，不够准确

## 正确实现：向偶数舍入

```verilog
function [WW-1:0] round_to_even;
    input [WW-1:0] in;
    reg [OW-1:0] result;
    reg guard, sticky, lsb;
    begin
        guard  = in[WW-OW];
        sticky = | in[WW-OW-1:0];
        lsb    = in[WW-OW+1];  // 保留位的最低位

        if (guard && (sticky || lsb))
            result = in[WW-1 : WW-OW] + 1;
        else
            result = in[WW-1 : WW-OW];
        round_to_even = {result, {(WW-OW){1'b0}}};
    end
endfunction
```

## 总结

| 方法 | 是否无偏 | 实现复杂度 | 适用场景 |
|------|----------|------------|----------|
| 截断（Truncate） | 有偏（向下） | 低 | 快速、低精度 |
| 四舍五入 | 有偏（向上） | 中 | 一般用途 |
| **向偶数舍入** | ✅ 无偏 | 高 | **高精度 DSP、CORDIC、浮点** |

> [!TIP]  
> 在 FPGA 设计中，若精度要求高，应使用“向偶数舍入”；若资源紧张，可用你的代码作为**近似四舍五入**。
