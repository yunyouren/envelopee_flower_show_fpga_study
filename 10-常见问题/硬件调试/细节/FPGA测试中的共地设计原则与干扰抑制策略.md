> 📌 **核心原则**：在多数测试场景中，**FPGA 的地必须与外围电路（面包板、电源板、传感器等）共地**，否则系统无法正常工作甚至可能损坏器件。但在共地的同时需防范地线引入的噪声干扰。

- **别名**：统一参考地、信号基准一致性
- **应用场景**：FPGA 功能验证、原型开发、混合信号采集、外设接口调试

## 1. 为何必须“共地”？—— 统一电位参考

若 FPGA 地与其他电路地未连接，则各自“0 V”基准不一致，会导致严重的逻辑错误或硬件损伤。

### 🔹 核心作用
| 作用 | 说明 |
|------|------|
| 🧭 **统一电平参考** | 所有数字信号以 GND 为 0 V 基准，断开可能导致 FPGA 将“高电平”误判为“低”，反之亦然。|
| ⚡ **防止电位差击穿** | 若两地间存在数伏压差，电流反灌 IO 口，可能烧毁 FPGA 或外围 IC。|
| 🛡️ **降低随机干扰风险** | 不共地造成的浮动电位比可控的地环路更危险，在小规模测试中优先保证共地。|

> ▶️ 示例：FPGA 认为的“0 V”若比传感器地高出 1.5 V，则本应是“3.3 V”的高电平实际被接收为“1.8 V”，处于不确定区，导致误触发。

### 💡 注意事项（普通测试场景）
- 使用 **粗而短的导线**（≥16 AWG）直接连接各部分 GND。
- 推荐采用 **星型接地拓扑**：FPGA GND、电源 GND、面包板 GND 共同接到一个中心点，避免链式串联增加阻抗。
- 面包板布线时确保接地条连续导通（可用万用表检测）。

## 2. 特殊情况：何时可以“不共地”？

仅在特定需求下允许隔离两地，但仍需保持信号回路完整。

### 🔹 隔离型电源场景
当使用带有电气隔离的电源模块（如 AC-DC 模块带变压器/光耦）且面对高压或强干扰环境时：

- ✅ 允许 FPGA 地与外围地分开；
- ❗ 必须通过 **隔离器件** 实现信号通信，例如：
  - 数字隔离器（如 ADuM 140 x、Si 86 xx）
  - 光耦（如 PC 817、6 N 137）
  - 隔离 ADC/DAC、隔离运放
- 🔋 两侧需配备独立供电电源，不能共享 VCC 或 GND。

> 🚫 警告：不可简单断开地线却不加隔离器件——这会形成天线效应，放大 EMI 干扰！

## 3. 共地带来的潜在干扰及其根源

尽管共地是基础要求，但不当接法仍可能引入噪声，主要来自两大机制：

| 干扰类型 | 成因 | 影响对象 | 发生条件 |
|----------|------|-----------|------------|
| 地电位差噪声 | 地线阻抗 + 大电流 → ΔV = I×R | 数字逻辑判断、ADC 输入 | 开关负载、电机驱动 |
| 地环路感应 | 闭合地环耦合电磁场 → 感应电流 | 模拟信号、低速总线 | 存在变频设备、长走线 |
| 共模转差模干扰 | 接地不平衡 → 噪声差值 | UART/SPI/I²C 总线 | 强静电、电网波动 |
| 高频传导噪声 | 开关电源/高速数字电路经地线耦合 | 时钟、复位、PLL | MHz 以上开关频率 |

📌 **根本原因总结**：
地不是理想零阻抗路径 → 任何电流流过都会产生电压 → 这个电压成为“伪信号”。

---

## 4. 抑制干扰的三大策略

解决思路：**共地前提下，切断噪声路径**

### 策略一：降低地线阻抗 —— 减少地电位差

| 方法 | 实施方式 | 效果 |
|------|---------|--------|
| 使用粗短接地线 | 选用 ≥16 AWG 导线，尽量直线连接，避免绕圈 | 显著降低电阻与感抗 |
| 区分 AGND / DGND | 模拟地与数字地单独走线，在电源入口单点汇接（可用 0Ω 电阻或磁珠） | 避免数字噪声污染模拟采样 |
| PCB 设置接地平面 | 自制测试板底层铺铜，并多点接入 FPGA GND 引脚 | 提供极低阻抗返回路径 |

💡 **面包板提示**：尽量不用跳线跨板连接地，改用专用粗线从电源输出端直连所有地节点。

---

### 策略二：抑制地环路 —— 减少电磁感应

| 方法 | 说明 |
|------|------|
| 星型接地（Star Grounding） | 所有地汇聚于一点，避免形成大环路，减少感应面积 |
| 差分信号传输 | 如 LVDS、RS 485、USB 等，天然抵抗共模噪声（含地漂移） |
| 使用隔离器件切断地环 | 在干扰源侧（如电机驱动）使用光耦或数字隔离器，彻底断开地路径 |

✅ 应用示例：
```text
[电机控制器] —(光耦隔离)—> [FPGA]
                 ↑
          独立供电 & 独立地
```

> 此时地环打开，即使电机产生强干扰也不会反馈至 FPGA。

---

### 策略三：滤波与屏蔽 —— 阻断噪声传播路径

| 措施 | 应用位置 | 目的 |
|------|--------|------|
| 去耦电容 | FPGA 电源引脚附近（100 nF + 10μF） | 滤除高频噪声 |
| 磁珠或电感 | 开关电源输出端串联 | 抑制传导干扰 |
| RC 滤波/TVS 管 | 传感器输入前级 | 抗尖峰、静电、振铃 |
| 屏蔽电缆 + 单端接地 | 长距离模拟信号线 | 防止空间耦合干扰 |
| 布线避让 | 时钟线远离大电流线 | 减少串扰 |

🔍 关键细节：
- 屏蔽层**只在一端接地**（通常接 FPGA 侧），防止两端接地造成新地环。
- TVS 管用于防 ESD 和瞬态浪涌，保护 FPGA IO。

## 5. 实战建议：不同场景下的接地方案

| 测试类型 | 推荐接地方案 |
|---------|----------------|
| 🟢 **基础功能测试**（LED、按键、SPI Flash） | 直接共地 + 星型连接 + 去耦电容 |
| 🟡 **混合信号测试**（ADC + 数字控制） | 分区布地（AGND/DGND），电源入口单点连接 |
| 🔴 **工业级干扰环境**（电机、变频器旁） | 隔离信号 + 差分通信 + 独立电源 + 屏蔽线 |
| 🔵 **自制 PCB 板测试** | 设计完整地平面 + 多过孔连接 + 分割模拟/数字区域 |

## ✅ 总结：基本原则一览表

| 原则 | 是否强制 | 备注 |
|------|----------|------|
| ✅ 必须共地 | ✔️ 是 | 绝大多数测试场景的基础要求 |
| ✅ 使用粗短地线 | ✔️ 推荐 | 显著提升稳定性 |
| ✅ 加去耦电容 | ✔️ 强烈推荐 | 每个电源引脚都应配置 |
| ⚠️ 区分模拟/数字地 | ✔️ 视情况 | 仅适用于涉及 ADC/DAC 的系统 |
| ⚠️ 使用隔离器件 | ➖ 特殊场景 | 用于高压、强干扰场合 |
| ❌ 完全断开地线 | ✖️ 禁止 | 除非配合电气隔离机制 |

> 🔄 记住：**“共地是前提，低阻是关键，分区是补充，隔离是例外。”**
