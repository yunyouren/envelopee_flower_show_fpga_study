> **目标**：确保上板测试**安全、高效、一次成功**  
## 🔴 一、程序设计层面（RTL & 综合）

| 检查项            | 要求                                            | 风险等级 | 工程提示                                              |
| -------------- | --------------------------------------------- | ---- | ------------------------------------------------- |
| ==**寄存器初始化**== | 所有寄存器（控制、状态、计数器等）必须初始化包括复位后的（如 `rst_n` 有效时清零） | ⚠️ 高 | FPGA 上电后寄存器状态**不确定**，未初始化易导致状态机跑飞、计数器溢出           |
| **存储单元初始化**    | RAM、FIFO、ROM 等需初始化（清零或写入已知 Pattern）           | ⚠️ 中 | 避免读出随机值干扰数据通路，尤其在启动阶段                             |
| **时钟设计正确性**    | 时钟源（外部晶振 / PLL 输出）频率、相位符合设计；已添加时钟约束           | ⚠️ 高 | 使用 `create_clock` / `create_generated_clock` 显式约束 |
| **复位逻辑完整**     | 复位类型（同步/异步）合理，覆盖所有关键模块，复位释放无毛刺                | ⚠️ 高 | 推荐使用**异步复位、同步释放**（Async Assert, Sync Deassert）    |
| **冗余逻辑清理**     | 删除未例化模块、注释掉调试代码、移除死代码                         | ⚠️ 低 | 防止综合工具误综合，节省资源，提升可读性                              |
| **条件编译正确**     | `ifdef` / `ifndef` 宏定义与当前工程配置一致               | ⚠️ 中 | 检查顶层 Makefile 或工程设置中的宏开关                          |

> ✅ **最佳实践**：在顶层模块中统一管理复位信号，避免模块间复位不一致。

## 🔴 二、IO 与硬件配置层面

| 检查项                | 要求                                                 | 风险等级  | 工程提示                                |
| ------------------ | -------------------------------------------------- | ----- | ----------------------------------- |
| **引脚绑定正确**         | 所有使用引脚已通过 Pin Assignment 绑定，与 PCB 原理图一致            | ⚠️ 高  | **重点核对**：时钟、复位、高速接口（如 DDR、SerDes）   |
| ==**未用 IO 安全配置**== | - 输入引脚：上拉/下拉（Pull-up/down）<br>- 输出引脚：高阻（Tri-state） | ⚠️ 中  | 防止悬空引脚引入噪声或造成短路                     |
| **电平标准匹配**         | 每个 IO Bank 的 I/O Standard（如 LVCMOS 33、LVDS）与外设一致   | ⚠️ 高  | 不匹配可能导致**信号失真**或**芯片损坏**            |
| ==**VCCIO 供电正确**== | 对应 Bank 的 VCCIO 电压已在硬件上正确供电（如 3.3 V、1.8 V）         | ⚠️ 极高 | **严禁**软件配置 3.3 V 而硬件接 1.8 V！可能烧毁 IO |
| **驱动能力设置**         | 高速信号（≥100 MHz）驱动电流（如 8 mA、12 mA）按负载配置              | ⚠️ 中  | 驱动不足 → 信号边沿缓；驱动过强 → EMI 增加          |
| **终端匹配**           | 高速信号线添加终端电阻（如 50Ω 串联 / 100Ω 差分并联）                  | ⚠️ 中  | 尤其适用于长走线、背板连接、高速 SerDes             |
| **差分信号极性**         | LVDS/HSTL 等差分对的 P/N 极性与 PCB 一致                     | ⚠️ 高  | 极性反接 → 信号反相，通信失败                    |

> ✅ **最佳实践**：使用 FPGA 厂商提供的 **IBIS 模型**进行信号完整性仿真（如 HyperLynx、ADS）。

## 🔴 三、时序与资源层面

| 检查项 | 要求 | 风险等级 | 工程提示 |
|--------|------|----------|----------|
| **完整时序约束** | - 主时钟、衍生时钟均已约束<br>- 输入/输出延迟（I/O Delay）按外设 datasheet 设置 | ⚠️ 高 | 缺少约束 → 工具按默认 1 ns 优化，**时序不可信** |
| **时序收敛** | 所有路径 Slack ≥ 0（建议 ≥ 0.2 ns 余量） | ⚠️ 极高 | 关注 **WNS（Worst Negative Slack）** 和 **TNS（Total Negative Slack）** |
| **资源占用合理** | - LUT/FF ≤ 70%<br>- BRAM/DSP/PLL ≤ 80% | ⚠️ 中 | 超过 85% 易导致布局布线失败或时序恶化 |
| **无资源冲突** | 同一 PLL、SerDes、硬核 IP 未被重复调用或超限使用 | ⚠️ 高 | 查看综合报告中的 **Resource Utilization** 表 |

> ✅ **最佳实践**：对关键路径手动插入寄存器（流水线），或使用 `(* keep *)` 保留优化边界。

## 🔴 四、功能与安全验证

| 检查项 | 要求 | 风险等级 | 工程提示 |
|--------|------|----------|----------|
| **仿真全覆盖** | - 功能仿真（RTL + Gate-level）<br>- 覆盖：正常流程、边界条件、异常场景（复位、错误输入） | ⚠️ 高 | 使用 UVM 或定向测试 + 断言（assert）验证 |
| **无逻辑漏洞** | 无死锁、状态机非法跳转、数据丢失、溢出等问题 | ⚠️ 高 | 状态机建议使用 **one-hot + default state** |
| **电源上电顺序** | VCCINT、VCCIO、VCCAUX 等上电时序符合芯片手册要求 | ⚠️ 极高 | 违反顺序可能导致**闩锁效应（Latch-up）**，永久损坏芯片 |
| **电流保护** | FPGA **不直接驱动**大电流负载（如电机、LED 阵列） | ⚠️ 极高 | 通过 MOSFET、驱动 IC 隔离，FPGA IO 电流通常 ≤ 12 mA/引脚 |
| **接地可靠性** | - 数字地（DGND）与模拟地（AGND）隔离合理<br>- GND 引脚低阻抗连接 | ⚠️ 中 | 高速系统建议使用 **多点接地 + 地平面** |

> ✅ **最佳实践**：上电前用万用表测量各电源对地电阻，排除短路风险。

## 🔴 五、下载与调试准备

| 检查项 | 要求 | 风险等级 | 工程提示 |
|--------|------|----------|----------|
| **下载配置正确** | - 下载方式（JTAG / SPI Flash）配置无误<br>- 下载线缆驱动正常（如 USB Blaster、FTDI） | ⚠️ 低 | 首次上板建议用 **JTAG**，避免 Flash 配置失败无法调试 |
| **比特流文件有效** | .bit（Xilinx）或 .sof（Intel）文件生成成功，版本匹配 | ⚠️ 中 | 检查文件时间戳，防止误用旧版本 |
| **调试接口预留** | - 关键信号接入 ILA（Vivado）或 SignalTap（Quartus）<br>- 虚拟引脚（Virtual Pin）用于内部信号观测 | ⚠️ 中 | 调试信号建议包含：时钟、复位、状态机状态、数据有效标志 |
| **触发条件预设** | 设置触发条件（如 `data_valid && addr==0x10`）便于捕获异常 | ⚠️ 低 | 避免“大海捞针”式调试 |

> ✅ **最佳实践**：在顶层模块中定义 `DEBUG_MODE` 宏，控制是否插入 ILA，便于版本管理。

## 🛡️ 风险等级说明

- **极高**：可能导致**芯片损坏、硬件烧毁**
- **高**：大概率导致**功能失效、时序崩溃**
- **中**：可能引起**间歇性错误、调试困难**
- **低**：影响效率或可维护性，一般不致命

## 📌 上板前最后五问（快速自检）

1. **所有电源电压是否测量正常？**（VCCINT, VCCIO, VCCAUX）
2. **复位信号是否能可靠拉低并释放？**
3. **时钟是否起振？**（可用示波器或 ILA 观测）
4. **关键 IO 电平是否匹配？**（FPGA 3.3 V ↔ 外设 3.3 V？）
5. **仿真是否覆盖了启动流程？**

> ✅ 若任一问题答案为“否”，**禁止上板！**
