## 🎯 学习路径

### 初学者路径
1. **数制与编码** → 理解二进制、十六进制
2. **逻辑门电路** → 掌握基本逻辑运算
3. **组合逻辑** → 学习组合电路设计
4. **时序逻辑** → 理解时钟和状态概念

### 进阶路径
1. **复杂组合逻辑** → 编码器、译码器、多路选择器
2. **时序电路分析** → 状态图、时序图分析
3. **电路优化** → 逻辑化简、卡诺图
