# ⚡ FPGA时序约束速查手册

> 快速查找常用时序约束命令、参数和解决方案

## 🔧 常用约束命令

### Vivado (XDC)
```tcl
# 时钟约束
create_clock -period 10.0 [get_ports clk]
create_generated_clock -source [get_ports clk] -divide_by 2 [get_pins pll/clk_out]

# 输入延迟
set_input_delay -clock clk -max 2.0 [get_ports data_in]
set_input_delay -clock clk -min 1.0 [get_ports data_in]

# 输出延迟  
set_output_delay -clock clk -max 3.0 [get_ports data_out]
set_output_delay -clock clk -min 1.5 [get_ports data_out]

# 虚假路径
set_false_path -from [get_clocks clk_a] -to [get_clocks clk_b]

# 多周期路径
set_multicycle_path -setup 2 -from [get_pins reg_a/C] -to [get_pins reg_b/D]
```

### Quartus (SDC)
```tcl
# 时钟约束
create_clock -period 10.0 [get_ports {clk}]
create_generated_clock -source [get_ports {clk}] -divide_by 2 [get_pins {pll|altpll_component|auto_generated|pll1|clk[0]}]

# 输入延迟
set_input_delay -clock clk -max 2.0 [get_ports {data_in[*]}]
set_input_delay -clock clk -min 1.0 [get_ports {data_in[*]}]

# 输出延迟
set_output_delay -clock clk -max 3.0 [get_ports {data_out[*]}]
set_output_delay -clock clk -min 1.5 [get_ports {data_out[*]}]
```

## 📊 时序分析命令

### Vivado
```tcl
# 时序报告
report_timing_summary
report_timing -slack_lesser_than 0 -max_paths 10
report_timing -from [get_pins reg_a/C] -to [get_pins reg_b/D]

# 时钟分析
report_clocks
report_clock_interaction

# 跨时钟域分析
report_cdc
```

### Quartus
```tcl
# 时序报告
report_timing -setup -npaths 10
report_timing -hold -npaths 10
report_timing -recovery -npaths 10
report_timing -removal -npaths 10

# 时钟分析
report_clocks
```

## ⚠️ 常见时序问题速查

| 问题现象 | 可能原因 | 解决方案 |
|---------|---------|---------|
| Setup违例 | 组合逻辑延迟过长 | 插入流水线、降低扇出 |
| Hold违例 | 路径延迟过短 | 插入缓冲器、调整布局 |
| 跨时钟域问题 | 缺少同步器 | 添加双触发器同步器 |
| 高扇出问题 | 一个信号驱动太多负载 | 插入缓冲树、复制信号 |

## 🎯 优化策略优先级

1. **RTL级优化**（最有效）
   - 流水线插入
   - 扇出控制
   - 算法优化

2. **约束优化**
   - 精确时钟约束
   - 虚假路径设置
   - 多周期路径

3. **物理实现优化**
   - 布局约束
   - 布线约束
   - 时钟域规划

## 📏 时序裕量目标

| 时序类型 | 推荐裕量 | 说明 |
|---------|---------|------|
| Setup | ≥ 15% × 时钟周期 | 确保频率稳定 |
| Hold | ≥ 0.1-0.3 ns | 工具通常自动修复 |
| Recovery | ≥ 0.2 ns | 异步复位恢复 |
| Removal | ≥ 0.1 ns | 异步复位移除 |

## 🔍 调试技巧

### 1. 定位关键路径
```tcl
# 找出最差的10条路径
report_timing -slack_lesser_than 0 -max_paths 10 -nworst 1

# 分析特定模块
report_timing -through [get_pins module_name/*]
```

### 2. 时钟域分析
```tcl
# 检查时钟关系
report_clock_interaction

# 查看时钟树
report_clock_networks
```

### 3. 资源使用分析
```tcl
# Vivado
report_utilization

# Quartus  
report_resource_usage
```
