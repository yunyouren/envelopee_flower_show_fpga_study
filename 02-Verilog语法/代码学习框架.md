## 1. **模块的输入与输出（I/O Interface）**

| 信号名 | 方向 | 位宽 | 数据类型 | 说明 |
|--------|------|------|----------|------|
| `clk` | 输入 | 1 bit | 时钟信号 | 系统主时钟 |
| `rst` | 输入 | 1 bit | 复位信号（高电平有效） | 初始化内部状态 |
| `angle_in` | 输入 | 16 bit | 定点数（Q 15 格式） | 输入角度（0~2π 映射为 0~65535） |
| `start` | 输入 | 1 bit | 控制信号 | 启动 CORDIC 迭代 |
| `sine_out` | 输出 | 16 bit | 定点数（Q 15 格式） | 正弦值输出（范围 -32768 ~ 32767） |
| `cos_out` | 输出 | 16 bit | 定点数（Q 15 格式） | 余弦值输出（可选） |
| `done` | 输出 | 1 bit | 状态信号 | 迭代完成标志 |

> ✅ **关键点**：  
> - 所有数据为 **定点数 Q 15 格式**（1 位符号 + 15 位小数），避免浮点运算。  
> - `start` 和 `done` 构成**握手协议**，便于与其他模块协同。

## 2. **模块的原理（Working Principle）**

### 📌 核心思想：
CORDIC（**CO**ordinate **R**otation **DI**gital **C**omputer）是一种**迭代式坐标旋转算法**，通过一系列微小角度的旋转，将初始向量 `(x₀, y₀)` 旋转到目标角度 `θ`，最终 `y` 分量即为 `sin(θ)`，`x` 分量为 `cos(θ)`。

### 📌 数学原理（旋转模式）：
每一步迭代：
$$
\begin{cases}
x_{i+1} = x_i - d_i \cdot y_i \cdot 2^{-i} \\
y_{i+1} = y_i + d_i \cdot x_i \cdot 2^{-i} \\
z_{i+1} = z_i - d_i \cdot \arctan(2^{-i})
\end{cases}
$$
其中：
- $ d_i = \text{sign}(z_i) $：决定旋转方向（左或右）
- $ \arctan (2^{-i}) $：预存的角度查找表（LUT）
- 初始值：$ x_0 = K \approx 0.60725 $, $ y_0 = 0 $, $ z_0 = \theta $

> ⚠️ **注意**：由于每次旋转会放大向量长度，需乘以增益补偿系数 $K$（可硬件预乘或软件补偿）。

### 📌 为什么适合 FPGA？
- **无需乘法器**：用**移位 + 加减法**实现旋转。
- **资源节省**：适合资源受限的 FPGA。
- **可流水线化**：支持高吞吐设计。

## 3. **实现步骤（Implementation Steps）**

| 步骤 | 内容 |
|------|------|
| ① | **初始化**：设置初始值 $x_0 = K \times 2^{15}$, $y_0 = 0$, $z_0 = \theta$ |
| ② | **预计算角度表**：生成 `atan(2^{-i})` 的 Q 15 表（共 16 项） |
| ③ | **构建迭代单元**：每个时钟周期执行一次迭代（i=0 到 15） |
| ④ | **方向判断**：根据 `z_reg[i]` 的符号决定 $d_i$ |
| ⑤ | **移位操作**：用 `>> i` 实现 $ \times 2^{-i} $ |
| ⑥ | **状态机控制**：`IDLE → ITERATE → DONE` |
| ⑦ | **输出结果**：迭代完成后输出 `sine_out = y_reg`, `cos_out = x_reg` |

## 4. **使用场景、优点与缺点**

| 项目 | 内容 |
|------|------|
| ✅ **使用场景** | - 信号发生器（正弦/余弦波）<br>- 电机控制（FOC 算法中的角度计算）<br>- 通信系统（载波生成、调制解调）<br>- 雷达/声纳中的相位计算 |
| ✅ **优点** | - 无需硬件乘法器，节省 LUT/FF 资源<br>- 算法简单，易于硬件实现<br>- 支持多种模式（旋转、向量化）<br>- 可扩展为通用数学协处理器 |
| ❌ **缺点** | - 迭代方式导致**延迟较高**（16 周期/次）<br>- 精度受限于迭代次数<br>- 需要角度查找表（LUT）<br>- 增益 $K$ 需额外补偿 |

> 💡 **适用权衡**：适合**中低速、资源敏感**的应用；若需高速，可考虑查表法（LUT）或并行流水线 CORDIC。

## 5. **代码实现（Verilog 示例）**

```verilog
module cordic_sine (
    input      clk,
    input      rst,
    input      start,
    input  [15:0] angle_in,
    output reg [15:0] sine_out,
    output reg [15:0] cos_out,
    output reg       done
);

    parameter ITER = 16;
    localparam [15:0] K = 16'd19936; // 0.60725 * 32768

    // 角度查找表（atan(2^-i) in Q15）
    reg [15:0] angle_lut [0:ITER-1];
    initial begin
        angle_lut[0] = 16'd16384;  // atan(1)   ≈ 45°
        angle_lut[1] = 16'd9673;   // atan(0.5) ≈ 26.56°
        angle_lut[2] = 16'd5150;
        angle_lut[3] = 16'd2600;
        // ... 其他值可查表填充
    end

    reg [3:0]  iter_cnt;
    reg [15:0] x_reg, y_reg, z_reg;
    reg        valid;

    always @(posedge clk or posedge rst) begin
        if (rst) begin
            x_reg <= K;
            y_reg <= 16'd0;
            z_reg <= 16'd0;
            iter_cnt <= 0;
            valid <= 0;
            done <= 0;
            sine_out <= 0;
            cos_out <= 0;
        end else begin
            done <= 0;
            if (start) begin
                x_reg <= K;
                y_reg <= 0;
                z_reg <= angle_in;
                iter_cnt <= 0;
                valid <= 1;
            end else if (valid && iter_cnt < ITER) begin
                reg [15:0] x_next, y_next, z_next;
                reg [15:0] shift_x, shift_y;
                reg        d;

                d = (z_reg[15]) ? 1'b1 : 1'b0; // sign(z_reg)

                shift_x = (d == 1) ? y_reg >> iter_cnt : x_reg >> iter_cnt;
                shift_y = (d == 1) ? x_reg >> iter_cnt : y_reg >> iter_cnt;

                if (d)
                    x_next = x_reg + shift_y;
                else
                    x_next = x_reg - shift_y;

                if (d)
                    y_next = y_reg - shift_x;
                else
                    y_next = y_reg + shift_x;

                if (d)
                    z_next = z_reg + angle_lut[iter_cnt];
                else
                    z_next = z_reg - angle_lut[iter_cnt];

                x_reg <= x_next;
                y_reg <= y_next;
                z_reg <= z_next;
                iter_cnt <= iter_cnt + 1;
            end else if (iter_cnt == ITER) begin
                valid <= 0;
                sine_out <= y_reg;
                cos_out  <= x_reg;
                done <= 1;
            end
        end
    end

endmodule
```

## 6. **优化策略（Optimization）**

| 优化方向 | 方法 | 效果 |
|---------|------|------|
| **速度优化** | **流水线设计**：每个迭代阶段用独立寄存器，单周期完成一次迭代 | 提高吞吐率，适合高速应用 |
| **资源优化** | **串行迭代**：复用加法器/移位器，仅用一个迭代单元 | 减少 LUT/FF，适合资源紧张场景 |
| **精度优化** | 增加迭代次数（如 16→20），或使用补偿算法 | 提高输出精度 |
| **延迟优化** | 使用**预计算查找表（LUT）**替代 CORDIC，直接查 sin/cos 值 | 零延迟，但占用 BRAM 资源 |
| **并行化** | 同时生成 sin 和 cos（天然支持） | 提高数据利用率 |
| **定点优化** | 调整 Q 格式（如 Q 12）平衡精度与资源 | 更灵活适配系统需求 |

> 💡 **推荐策略**：  
> - 初学者：先实现**串行迭代版本**，理解原理。  
> - 进阶者：尝试**流水线版本**或**查表+Cordic 混合设计**。
