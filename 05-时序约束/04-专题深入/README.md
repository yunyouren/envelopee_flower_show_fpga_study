## 🔍 专题重点

### 跨时钟域设计 (CDC)
- **双触发器同步器**：最常用的CDC解决方案
- **握手协议**：复杂数据传输的可靠方法
- **FIFO设计**：异步时钟域间的数据缓冲

### 特殊路径处理
- **False Path**：逻辑上不存在的路径
- **Multi-cycle Path**：需要多个时钟周期的路径
- **Min/Max Delay**：特殊延迟约束

### 高级优化技巧
- **算法并行化**：提升吞吐量
- **资源共享**：减少面积开销
- **流水线深度优化**：平衡延迟和频率
