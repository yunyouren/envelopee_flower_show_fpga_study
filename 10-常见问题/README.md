## 20.不能直接使用PWM_OUT而必须使用pwm_out_reg的原因：
### 1. **Verilog语法限制**
- `PWM_OUT`被声明为`output [29:0] PWM_OUT`，默认是**wire类型**
- **wire类型信号不能在always块中进行过程赋值**（使用<=或=）
- wire类型只能通过**assign语句**或**模块实例化**进行连续赋值
### 2. **如果强行修改会发生什么**
如果将第48行改为：
```verilog
PWM_OUT <= 30'b0;  // 这会导致编译错误！
```
编译器会报错：**"Cannot assign to wire PWM_OUT in procedural assignment"**
### 3. **正确的解决方案**
要在always块中直接赋值给PWM_OUT，需要将其声明改为：
```verilog
output reg [29:0] PWM_OUT,  // 声明为reg类型
```
然后就可以直接在always块中赋值
